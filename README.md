> **Die modulare Plattform für Vereine, das Ehrenamt und weitere Organisationen.**

Bonni Core ist die zentrale Plattform und gemeinsame Grundlage für alle Anwendungen.

Es stellt grundlegende Funktionen wie Benutzerverwaltung, Rollen, Berechtigungen, Schnittstellen und weitere Systemdienste bereit. Anwendungen können diese Funktionen gemeinsam nutzen und sich auf ihre eigentlichen Aufgaben konzentrieren.

---

## Warum Bonni Core?

Bonni Core verfolgt einen modularen Ansatz.

Organisationen sollen genau die Werkzeuge nutzen können, die sie benötigen – nicht mehr und nicht weniger.

Dadurch bleibt Bonni Core übersichtlich, flexibel und kann gemeinsam mit den Anforderungen einer Organisation wachsen.

---

## Erweiterungen

Bonni Core kann durch verschiedene Erweiterungen ergänzt werden.

### App

Eine **App** ist eine eigenständige Anwendung mit einem größeren Funktionsumfang.

Sie erweitert Bonni Core um einen eigenen Aufgabenbereich.

**Beispiele:**

- StüberlApp
- HocketApp

### Add-on

Ein **Add-on** erweitert eine bestehende App um zusätzliche Funktionen.

Es eignet sich besonders für Funktionen, die nicht zum Kern einer Anwendung gehören oder von mehreren Anwendungen gemeinsam genutzt werden.

### Plugin

Ein **Plugin** erweitert Bonni Core oder eine Anwendung um kleinere Zusatzfunktionen.

Typische Beispiele sind:

- Druckertreiber
- Barcode-Scanner
- Geräteanbindungen
- Systemerweiterungen

---

## Kurz erklärt

| Typ | Beschreibung |
|------|--------------|
| **App** | Eigenständige Anwendung |
| **Add-on** | Erweiterung einer Anwendung |
| **Plugin** | Kleine Zusatzfunktion oder Geräteanbindung |

---

## Unsere Philosophie

Bonni Core soll Organisationen unterstützen – nicht einschränken.

Nicht eine große Anwendung löst alle Aufgaben.

Viele kleine Anwendungen lösen gemeinsam die richtigen Aufgaben.
