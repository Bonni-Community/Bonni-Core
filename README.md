# Bonni Core

> Software soll Menschen helfen, die anderen Menschen helfen.

> Organisationen wachsen mit ihren Aufgaben.
> Bonni wächst mit ihnen mit.

Bonni Core bildet die technische Grundlage für verschiedene Apps und Module.

Dazu gehören unter anderem die Verwaltung von Mitgliedern, Veranstaltungen, Geräten, Lagern, Finanzen sowie weiteren organisatorischen Aufgaben.

Bonni verfolgt einen modularen Ansatz. Organisationen sollen genau die Werkzeuge nutzen können, die sie benötigen nicht mehr und nicht weniger.
