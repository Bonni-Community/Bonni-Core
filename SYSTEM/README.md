# Bonni Core

Bonni Core ist die modulare Plattform für Vereine und Organisationen.

## Aufbau

- **[Backend](backend/)** verarbeitet Anfragen der Weboberfläche, prüft Anmeldung und Berechtigungen und liest oder speichert Daten in der Datenbank.
- **[Frontend](frontend/)** ist die Oberfläche im Browser. Es zeigt die Anmeldung, die Navigation und die Funktionen von Bonni an und spricht über die API mit dem Backend.
- **Apps, Add-ons und Plugins** erweitern den Core und werden als eigene Pakete veröffentlicht.

Installationspakete findest du im Bereich **Releases**. Die Lizenzinformationen stehen in [LICENSE.md](../LICENSE.md).
