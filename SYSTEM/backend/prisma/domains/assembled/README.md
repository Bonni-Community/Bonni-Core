# Prisma Assembly-Ziel

Dieser Ordner ist **kein fachlicher Quellordner** von Bonni Core.

Hier legt Bonni Core später beim Installieren von Erweiterungen die technisch zusammengesetzten Prisma-Dateien ab:

- `app/` für Apps, zum Beispiel StüberlApp oder HocketApp
- `add-on/` für Add-ons, zum Beispiel POS oder Timecapsule
- `plug-in/` für Plug-ins, zum Beispiel Task

Die fachlichen Quellen bleiben in den jeweiligen Paketen selbst.
