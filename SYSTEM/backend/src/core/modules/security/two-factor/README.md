# Two-factor authentication

Kanonische Core-Security-Implementation für accountgebundene TOTP-Einrichtung, Admin-Freigabeauftrag, QR-Ausgabe nur an den Zielaccount, Recovery-Codes, Challenges, Lockout und optionale externe Provideradapter.

`platform/security/two-factor` ist nur eine befristete Import-Kompatibilität und enthält keine Fachlogik.
